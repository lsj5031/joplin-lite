# Ask agent upstream attribution

The Ask agent is an original Joplin Lite implementation. Its portable execution
and tool-call patterns are derived from the MIT-licensed **pi-accanto** project
by lsj5031 at commit `c5f7b1a6fc4281201b5f9eb293bf00281f48ab7a`.

- `src/models.ts` follows `panel.js`: `createModels`, `createProvider`, a
  host-managed key placeholder, and the OpenAI-compatible Chat Completions
  stream functions.
- `src/tools.ts` and `src/instructions.ts` follow the bounded-read and
  evidence-first behavior of `attachments.js` and `research.js`, adapted to
  Joplin notes instead of page tabs.
- `src/entry.ts` follows the `Harness.open` → `root.configure` →
  `root.submit` → `submission.wait` / `root.abort` lifecycle in `panel.js`.

pi-accanto is MIT licensed. Its license is reproduced at
`tmp/pi-accanto/LICENSE` in a development checkout; the release notes here
record the origin rather than importing browser-only code.

- `@earendil-works/pi-ai` 1.4.0 — MIT.
- `@earendil-works/pi-durable` 1.4.0 — MIT.
- `@earendil-works/chord` 1.4.0 — MIT.

The embedded bundle is generated by `agent/build.mjs`; it contains no Node,
Chrome, IndexedDB or Worker runtime.
